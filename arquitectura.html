Cómo funciona "0xhacky publicador"

Herramienta interna, sin interfaz pública y sin otros usuarios. Solo publica los videos del propio canal 0xhacky.

Arquitectura

1. Guion del video (archivo JSON en un repositorio privado de GitHub)

↓

2. GitHub Actions renderiza el video vertical (Remotion, 1080x1920) a la hora programada

↓

3. Se pide un access token a Google con el refresh token del canal (guardado cifrado como secreto de GitHub)

↓

4. YouTube Data API v3: videos.insert (subida reanudable del MP4 con título, descripción y etiquetas) y channels.list (comprobar el canal)

↓

5. El Short queda publicado en youtube.com/@0xhacky; el enlace se guarda en el repositorio

Flujo del usuario (único usuario: el dueño del canal)

  1. Una sola vez, el dueño autoriza la app con OAuth 2.0 (pantalla de consentimiento de Google, permisos youtube.upload y youtube.readonly).
  2. El refresh token se guarda directamente como secreto cifrado; nadie lo ve.
  3. Cada día, el sistema sube los videos del canal sin intervención.
  4. El dueño puede revocar el acceso en myaccount.google.com/permissions; desde ese momento la herramienta deja de funcionar.

Datos

No se leen ni guardan datos de espectadores ni de otros canales. Ver la política de privacidad.
