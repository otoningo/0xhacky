Upload interface: GitHub Actions workflow "Publicar reel" (repo otoningo/hackrlarp-reels)

- name: Subir a YouTube (API oficial)
  env:
    YOUTUBE_CLIENT_ID: ${{ secrets.YOUTUBE_CLIENT_ID }}
    YOUTUBE_CLIENT_SECRET: ${{ secrets.YOUTUBE_CLIENT_SECRET }}
    YOUTUBE_REFRESH_TOKEN: ${{ secrets.YOUTUBE_REFRESH_TOKEN }}
  run: node scripts/publicar-youtube.mjs "$EP" out/reel.mp4

What the tool sends (scripts/publicar-youtube.mjs)

POST https://oauth2.googleapis.com/token            (refresh_token -> access_token)
GET  https://www.googleapis.com/youtube/v3/channels?part=snippet&mine=true
POST https://www.googleapis.com/upload/youtube/v3/videos?uploadType=resumable&part=snippet,status
     snippet: { title, description (+ #Shorts), tags, categoryId: "28", defaultLanguage: "es" }
     status:  { privacyStatus: "public", selfDeclaredMadeForKids: false, containsSyntheticMedia: true }
PUT  <upload URL>   (MP4 1080x1920, 30-60 s)
